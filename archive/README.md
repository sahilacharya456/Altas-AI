# Archived Code

This folder contains source that is not part of the active AltasAI runtime.

Active runtime:

- Mobile app: `apps/mobile`
- Backend API: `backend/api`
- Firebase: Auth, Firestore rules, and indexes

Archived source:

- `archive/backend_api_legacy`: previous Express/Mongo-style backend.
- `archive/mobile_api_legacy_services`: previous mobile legacy API client.
- `archive/functions`: previous Firebase Cloud Functions implementation.

Archived folders are not configured in `firebase.json`, are not part of the root npm workspaces, and should not be treated as production runtime.
