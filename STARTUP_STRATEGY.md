# AltasAI Startup Strategy

## What AltasAI Actually Is

A personal execution accountability system for ambitious people who have too many tasks, too many ideas, and not enough consistent follow-through. It is not a to-do app. It is not a chatbot. It is a daily signal capture + behavior analysis + strict mentor intervention loop.

## The Real Differentiator

The internal AI pipeline (deterministic, no Gemini required) means AltasAI works offline, has no hallucination risk on user data, costs nothing to run for basic features, and can give a specific next action from any device without an API call.

## What AltasAI Should NOT Be Yet

- A finance app
- A security scanner
- A news aggregator
- A health tracker
- A document AI
- A career planning tool

These are all present in the code. They should be hidden from the nav for launch.

## Best Target Users

1. Final-year CS/engineering students with major projects due
2. Junior developers building portfolios for job hunt
3. Indie builders shipping their first product
4. Early founders who have a working product but inconsistent execution

All share the same pain: they know what to do but struggle to do it consistently. AltasAI's strict mentor and daily execution loop directly attacks this.

## Best One-Line Positioning

**AltasAI: the strict AI mentor that tells you what to do today, holds you accountable to yesterday, and measures whether you're getting better.**

## North Star Metric

**Weekly completed execution loops per active user**  
An execution loop = `task created → focus started → task completed or reflected → intervention accepted or acted on`

This is better than DAU because it measures behavior change, not just opens.

## Main Startup Risk

The risk is not building the AI. The risk is whether the AI feedback produces behavior change repeatedly — and whether users return after the first week. The product must:
1. Track completed next actions (not just sent prompts)
2. Show the user their own pattern over 7–14 days
3. Make the first intervention hit personally (not generic)

## Monetization Path

**Free tier**: Core execution loop (tasks, focus, reflection, mentor basic)  
**Paid tier (~$9–12/month)**: 
- Cortex weekly report with full pattern analysis
- Unlimited mentor sessions
- Personalized interventions (ML-powered)
- Advanced execution history and streaks
- Strict accountability mode with daily check-ins

**Do not price on AI calls** — that creates anxiety. Price on value: becoming more disciplined.

## 90-Day Plan

**Days 1–30 (Demo-ready)**:
- P0 fixes done ✓
- Core loop works end-to-end on real device
- App Check + crash reporting configured
- Shared with 5–10 target users for feedback

**Days 31–60 (First 50 users)**:
- Onboarding funnel measured (completion rate)
- First execution loop completion tracked
- Mentor response quality reviewed weekly
- Weekly execution loop metric operational

**Days 61–90 (Revenue-ready)**:
- 7-day retention measured
- Paywall for premium Cortex report
- At least 10 users completing 3+ weekly loops
- Public launch on Product Hunt / LinkedIn

## Warning Signs to Watch

- Users create tasks but never start focus → onboarding problem
- Users start focus but never reflect → friction in reflection flow
- Mentor responses feel generic → intervention rules need tuning
- Users open app, read insight, close without action → UI needs a clearer "do this now" button
