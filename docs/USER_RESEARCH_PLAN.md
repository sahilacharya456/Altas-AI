# AltasAI User Research Plan

## Beta Cohort

Start with 20 to 50 users:

- students with final projects
- junior developers building portfolios
- indie builders
- early founders

## Interview Questions

Ask after 3 to 7 days:

- What did AltasAI help you do that you would not have done alone?
- Which recommendation felt accurate?
- Which recommendation felt useless?
- Did you trust the Mentor response?
- What made you come back or not come back?
- Was the app too broad?
- What would you pay for?

## Behavioral Data To Review

- onboarding completion
- tasks created per user
- focus sessions completed
- reflections submitted
- mentor prompts per active user
- recommendation acceptance
- ignored recommendations
- weekly execution loops

## Success Signal

The strongest signal is not compliments. It is repeated use.

Minimum beta target:

- 40% 7-day retention among target users
- 3+ weekly execution loops per retained user
- 30%+ recommendation acceptance rate
