# ATLAS AI Asset Plan

Use owned, generated, or royalty-free assets only. Keep app-critical assets in `apps/mobile/assets/images`.

## Current Required Assets

- `icon.png`, `adaptive-icon.png`, `notification-icon.png`, `splash.png`, and `favicon.png` are already present and referenced by `apps/mobile/app.json`.

## Optional Professional Visuals

- `hero-command-center.png`: abstract realistic AI dashboard with dark glass panels, cyan highlights, and no third-party logos.
- `empty-tasks.png`: minimal productivity desk scene with checklist, calendar, and soft lighting.
- `empty-goals.png`: clean roadmap/target visual for goal planning.
- `mentor-avatar.png`: neutral geometric AI mentor mark, not a human celebrity or branded robot.
- `security-scan.png`: shield and link analysis visual with a professional cyber dashboard style.

## Suggested Sources

- Generated bitmap assets with project-owned prompts.
- Unsplash, Pexels, or similar royalty-free libraries for non-branded background imagery.
- Expo-optimized PNG/WebP exports sized for mobile screens.

## Prompt Direction

Create realistic, premium SaaS/mobile dashboard visuals for "ATLAS AI", a personal discipline and focus operating system. Dark graphite interface, cyan and emerald accents, clean glass panels, realistic lighting, no logos, no text, no copyrighted characters, no brand marks.
