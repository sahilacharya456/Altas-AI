# AltasAI MVP Scope

## IN — Core Execution Loop (Ship These)

| Screen / Feature | Why |
|---|---|
| Auth (welcome, register, login) | Gate |
| Onboarding (discipline level, focus areas) | Personalization |
| Home dashboard | Daily command center |
| Tasks (create, complete, carry) | Core signal |
| Focus session | Core behavior |
| Reflection (nightly, honest assessment) | Core signal |
| AI Mentor chat | Engagement + advice |
| Cortex insight (internal, no Gemini required) | Differentiator |
| Interventions (proactive risk cards) | Retention trigger |
| Weekly report | Proof of value |
| Goals (active, progress tracking) | Long-horizon signal |
| Profile (discipline level, settings) | Personalization |

## OUT — Postpone to Post-Beta

| Screen / Feature | Reason |
|---|---|
| News screen | Placeholder, no backend |
| Device safety screen | Secondary security feature |
| Scan link screen | Secondary |
| Full Khata/finance module | Not the execution wedge |
| Digital discipline screen | Secondary |
| Behavior timeline | Advanced analytics |
| RAG system | Scaffolding only |
| RL contextual bandit | No reward signal |
| Vision / CV / OCR routes | Stubs |
| Health module (detailed) | Secondary |

## One-Line Positioning

**AltasAI turns daily tasks, reflection, and focus into one concrete next action — with a strict AI mentor that holds you accountable.**

## Target User

Final-year students, indie builders, and early founders who feel execution drift and want one system that tells them what to do today and why they failed yesterday.
