# AltasAI Startup Focus

## Strict Positioning

AltasAI should not launch as a generic life app. That is too broad and too hard to explain.

The launch wedge should be:

> AltasAI helps ambitious students, builders, and early founders stop drifting by turning tasks, reflections, and focus behavior into one concrete next action every day.

This is the marketable core. Every module should either improve this loop or wait.

## Core User

Primary early user:

- final-year student building a major project
- junior developer building a portfolio
- indie builder shipping a product
- early founder struggling with execution consistency

These users feel the pain daily, tolerate early product rough edges, and understand the value of a strict execution system.

## Product Promise

AltasAI should promise:

- Know what matters today.
- Understand why execution failed.
- Pick the next action.
- Start focus.
- Reflect honestly.
- Improve tomorrow.

Do not lead with finance, health, security, or document AI. Those are support modules, not the startup wedge.

## North Star Metric

Weekly completed execution loops:

```text
task selected -> focus started -> task completed or reflected -> intervention accepted
```

This is better than daily active users because it measures whether AltasAI changes behavior.

## Beta Metrics

Track:

- onboarding completion rate
- first task created
- first focus session started
- first reflection submitted
- mentor prompt submitted
- recommendation accepted
- next action completed
- 7-day retention
- weekly execution loops per active user

## What To Cut From Launch Scope

Delay these unless they directly support the core loop:

- broad finance dashboard
- broad health habit platform
- generic security assistant
- complex CV/document processing
- too many charts
- cinematic effects on practical screens

## Paid Product Hypothesis

Users may pay if AltasAI becomes their daily accountability and execution system, not if it is another AI chat screen.

Likely paid features:

- Cortex weekly report
- personalized interventions
- advanced memory/RAG
- strict mentor plans
- progress analytics
- saved execution history

## Startup Risk

The risk is not whether the app can generate advice. The risk is whether the advice produces behavior change repeatedly. The product must measure accepted recommendations and completed next actions.
